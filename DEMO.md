# 90-second demo script

Setup: VS Code (or terminal) with Claude Code visible, and `/mcp` showing **cometchat ✓ connected**. Two browser windows side by side, both on `http://localhost:5173`: one normal and one **incognito** (tabs in the same profile share CometChat's stored login). Allow camera and mic in both.

| Time | Show | Say |
| --- | --- | --- |
| 0:00–0:08 | Claude Code with the `cometchat` MCP listed, scroll past a `get_cometchat_implementation_bundle` / `fetch_cometchat_doc_page` call | "Built with Claude Code and the CometChat MCP." |
| 0:08–0:18 | Lobby → pick name + avatar in both windows → Enter town | "Pixel Town: chat that lives in space." |
| 0:18–0:35 | Walk the two avatars toward each other. The whisper panel slides in. Type in one window: the "•••" bubble appears over the head in the other. Send. | "Walk up to someone and a private DM opens. Typing shows over their head." |
| 0:35–0:40 | Press `1` and `4` for emotes | Transient messages, not stored. |
| 0:40–1:05 | Both walk into the **Lantern Café**. The HUD turns cyan and room chat opens. Send a message. Click **📹 Join call** in both. | "Step into a room: group chat and one shared video call." |
| 1:05–1:15 | Walk one avatar out the door. The call hangs up and the panels close. | "Walk away and it's over, like real life." |
| 1:15–1:25 | Close one window. The avatar disappears from the other. | Presence. |
| 1:25–1:30 | Logo + repo link | #ZeroToChat @CometChat |
