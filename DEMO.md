# 90-second demo script

Setup: VS Code (or terminal) with Claude Code visible, and `/mcp` showing **cometchat ✓ connected**. Two browser windows side by side, both on `http://localhost:5173`: one normal and one **incognito** (tabs in the same profile share CometChat's stored login). Allow camera and mic in both.

| Time | Show | Say |
| --- | --- | --- |
| 0:00–0:06 | Claude Code with the `cometchat` MCP listed, scroll past a `get_cometchat_implementation_bundle` / `fetch_cometchat_doc_page` call | "Built with Claude Code and the CometChat MCP." |
| 0:06–0:15 | Lobby → pick name + avatar in both windows → Enter town | "Pixel Town: chat that lives in space." |
| 0:15–0:28 | Walk the two avatars toward each other. The whisper panel slides in. Type in one window: the "•••" bubble appears over the head in the other. Send. | "Walk up to someone and a private DM opens. Typing shows over their head." |
| 0:28–0:33 | Press **📞 Call** in one window. The other window shows an incoming ring. Click **Accept**. Both see 1:1 video. | "Press C to whisper call—a 1:1 video call." |
| 0:33–0:38 | Walk one avatar away. The video call hangs up automatically. | Walk away and it ends. |
| 0:38–0:55 | Both walk into the **Lantern Café**. The HUD turns cyan and room chat opens. Send a message. Click **📹 Join call** in both. | "Step into a room: group chat and one shared video call." |
| 0:55–1:05 | Walk one avatar out the door. The call hangs up and the panels close. | Walk away and it closes. |
| 1:05–1:12 | Close one window. The avatar disappears from the other. | **Presence.** |
| 1:12–1:15 | Logo + repo link | #ZeroToChat @CometChat |
